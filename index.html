    1
    Classe e oggetto: lo stampo e il biscotto
    
  
    
    
    Una classe è un progetto: dice quali dati e quali azioni avrà una cosa, ma non è ancora una cosa vera. Un oggetto è una cosa vera costruita con quel progetto.
    
  
    
  
    
    
    Classe = modulo vuoto
    «Studente: età ___, matricola ___, media ___». Uno solo, vale per tutti.
    
    
    →
    
    
    Oggetti = moduli compilati
    Paolo: 18, 1001, 7.5
    Antonio: 17, 1002, 5.5
    Ognuno ha i suoi dati.
    
  
    
  
    class studente {
    ...
};              // il ; dopo la graffa è obbligatorio

studente Paolo;    // crea l'oggetto Paolo
studente Antonio;  // crea l'oggetto Antonio
    
  
    
    
    La riga studente Paolo; si legge come int x;: prima il tipo, poi il nome. Solo che qui il tipo l'abbiamo inventato noi: è la classe studente.
    
  
    
  
    Occhio: dopo la graffa che chiude la classe ci vuole il punto e virgola };. Dimenticarlo è l'errore più comune in verifica.
    
  
    
    
    Nel programma, chi sono gli oggetti?
    
    
    
    
    Giusto: Paolo e Antonio.studente è la classe (il progetto); eta, nmat e media sono i dati dentro ogni oggetto.
    
  
    
  
    

    


    
  
    2
    Gli attributi: i dati dello studente
    
  
    
    
    Gli attributi sono le variabili che stanno dentro la classe. Ogni oggetto ne ha una copia tutta sua: l'età di Paolo e l'età di Antonio sono due caselle diverse.
    
  
    
  
    int eta, nmat;   // due numeri interi
float media;     // un numero con la virgola
    
  
    
    
    AttributoTipoEsempioPerché quel tipo
    
    
      
    etaint18l'età è un numero intero
    
      
    nmatint1001la matricola è un numero intero
    
      
    mediafloat7.5la media può avere la virgola
    
        
  
    
  
    In C++ la virgola si scrive col punto: 7.5, non 7,5. Vale anche quando scrivi i numeri da tastiera mentre il programma gira.
    
  
    
    
    Perché media è float e non int?
    
    
    
    
    Esatto.Un int tiene solo numeri interi: 6.5 diventerebbe 6 e la parte dopo la virgola andrebbe persa.
    
  
    
  
    

    


    
  
    3
    public e private: chi può toccare i dati
    
  
    
    
      
      
    • public: si può usare anche da fuori la classe, per esempio da main.
      • 
      
    • private: si può usare solo dentro la classe, cioè nei suoi metodi.
      • 
    
    
    
    Nel codice c'è scritto public: due volte. Funziona, ma la regola delle classi dice che i dati vanno messi private e i metodi public. Così i dati si cambiano solo passando dai metodi: si chiama incapsulamento.
    
  
    
  
    class studente {
private:              // al posto del primo public:
    int eta, nmat;
    float media;
public:               // i metodi restano pubblici
    ...
};
    
  
    
    
    Con public
    Da main si può scrivere Paolo.media = 15; e nessuno controlla che sia un voto sensato.
    
    
    →
    
    
    Con private
    Paolo.media = 15; dà errore di compilazione. Si deve passare da Paolo.set_media(15);, che può controllare il valore.
    
  
    
  
    Da sapere: in una class, se non scrivi niente, tutto è private.
    
  
    
    
    Se media fosse private, cosa succederebbe con Paolo.media = 7; dentro main?
    
    
    
    
    Giusto.Un attributo private si usa solo dentro i metodi della classe. Da main bisogna usare Paolo.set_media(7);.
    
  
    
  
    

    


    
  
    4
    Il costruttore: quando l'oggetto nasce
    
  
    
    
    Il costruttore è un metodo speciale che parte da solo quando l'oggetto viene creato. Si riconosce perché:
    
    
      
      
    • ha lo stesso nome della classe (studente);
      • 
      
    • non ha tipo davanti, nemmeno void.
      • 
    
    
    
    Nel codice ce ne sono due:
    
  
    
  
    studente() {                          // 1) senza parametri
    eta = 0; nmat = 0; media = 0;     // mette tutto a zero
}
studente(int e, int matr, float m) {  // 2) con tre parametri
    eta = e; nmat = matr; media = m;  // copia i valori ricevuti
}
    
  
    
    
    Se scriviParte il costruttoreRisultato
    
    
      
    studente Paolo;senza parametrieta 0, nmat 0, media 0
    
      
    studente Luca(19, 3003, 8.5);con tre parametrieta 19, nmat 3003, media 8.5
    
        
  
    
  
    
    
    Due metodi con lo stesso nome ma parametri diversi: si chiama overloading. Il compilatore sceglie quello giusto guardando quanti valori gli passi.
    
    
    Nel main del codice viene usato solo il primo: il secondo esiste ma nessuno lo chiama.
    
  
    
  
    Occhio: scrivi studente Paolo; senza parentesi. Con le parentesi vuote, studente Paolo();, il compilatore non crea un oggetto.
    
  
    
    
    Che valori ha Paolo subito dopo studente Paolo;?
    
    
    
    
    Esatto.Parte il costruttore senza parametri, che mette tutti gli attributi a 0. I valori da tastiera arrivano dopo, con i set.
    
  
    
  
    

    


    
  
    5
    I metodi get e set: leggere e scrivere
    
  
    
    
    Un metodo è una funzione che sta dentro la classe. Quelli che iniziano con get e set sono le «porte» per arrivare agli attributi.
    
  
    
  
    
    
    get = leggi
    int get_eta() { return eta; }
    Non riceve niente, restituisce il valore. Il tipo davanti è quello dell'attributo.
    
    
    ↔
    
    
    set = scrivi
    void set_eta(int e) { eta = e; }
    Riceve un valore (il parametro e) e lo copia nell'attributo. Non restituisce niente: void.
    
  
    
  
    
    
    Attributogetset
    
    
      
    etaint get_eta()void set_eta(int e)
    
      
    nmatint get_nmat()void set_nmat(int matr)
    
      
    mediafloat get_media()void set_media(float m)
    
        
  
    
  
    Per usarli da main si scrive oggetto, punto, metodo: Paolo.set_eta(18); scrive 18 nell'età di Paolo; Paolo.get_eta() la legge.
    
  
    Nel codice i get esistono ma non vengono mai usati: in main ci sono solo i set.
    
  
    
    
    Che tipo restituisce get_media()?
    
    
    
    
    Giusto.Il get restituisce l'attributo, quindi ha lo stesso tipo dell'attributo: float get_media().
    
  
    
  
    

    


    
  
    6
    visualizzadati: stampare con cout
    
  
    
    
    cout scrive sullo schermo. Le frecce << mettono in fila i pezzi da stampare:
    
    
      
      
    • il testo tra virgolette viene stampato così com'è;
      • 
      
    • una variabile viene sostituita dal suo valore.
      • 
    
    
  
    
  
    cout << "eta è: " << eta;   // se eta vale 18 stampa: eta è: 18
    
  
    Problema: nel codice non si va mai a capo. Con Paolo (18, 1001, 7.5) lo schermo mostra tutto attaccato:
    
  
    eta è: 18la matricola è: 1001la media è: 7.5
    
  
    Per andare a capo si aggiunge endl (oppure "\n"):
    
  
    void visualizzadati() {
    cout << "eta è: " << eta << endl;
    cout << "la matricola è: " << nmat << endl;
    cout << "la media è: " << media << endl;
}
    
  
    eta è: 18
la matricola è: 1001
la media è: 7.5
    
  
    Curiosità: sul terminale di Windows le lettere accentate come «è» possono uscire come simboli strani. Non è un errore del programma.
    
  
    
    
    Se nmat vale 1001, cosa stampa cout << "matricola" << nmat;?
    
    
    
    
    Giusto: matricola1001.cout non aggiunge spazi da solo. Per avere lo spazio bisogna scriverlo dentro le virgolette: "matricola ".
    
  
    
  
    

    


    
  
    7
    esitofinale: if, else e return
    
  
    int esitofinale() {
    if (media >= 6) {         // se la media è maggiore o uguale a 6
        cout << "promosso";
        return 1;              // esce e restituisce 1
    } else {                   // altrimenti (media minore di 6)
        cout << "bocciato";
        return 0;              // esce e restituisce 0
    }
}
    
  
    
    
      
      
    • >= vuol dire «maggiore o uguale»: con 6 esatto si è promossi.
      • 
      
    • return fa due cose: termina il metodo e consegna un valore a chi l'ha chiamato.
      • 
      
    • Il metodo è int perché restituisce un numero: 1 per promosso, 0 per bocciato.
      • 
    
    
    
    Nel main si scrive solo Paolo.esitofinale();: il numero restituito non viene salvato da nessuna parte, quindi va perso. Resta solo la scritta sullo schermo.
    
  
    
  
    L'esercizio nascosto nel commento
    
  
    Nel codice c'è un commento che chiede un metodo promosso() che restituisca true se la media è maggiore o uguale a 6, false altrimenti. Vero o falso si dice bool:
    
  
    bool promosso() {
    if (media >= 6)
        return true;
    else
        return false;
}

// versione corta, fa la stessa cosa:
bool promosso() { return media >= 6; }
    
  
    Differenza con esitofinale: promosso() non stampa niente, risponde solo vero o falso. Poi in main si usa così: if (Paolo.promosso()) cout << "Paolo promosso";
    
  
    
    
    Antonio ha media 6. Cosa stampa Antonio.esitofinale();?
    
    
    
    
    Giusto: promosso.6 >= 6 è vero. Il valore 1 viene restituito ma non stampato, perché nessuno lo mette in un cout.

    Il main: leggere con cin e usare gli oggetti
    
  
    
    
    main è il punto da cui parte il programma. Fa quattro cose, in quest'ordine:
    
    
      
      
    1. Prepara le variabili d'appoggio e, matr, m: servono per leggere da tastiera. Non sono gli attributi!
      2. 
      
    2. Crea gli oggetti Paolo e Antonio (con tutto a 0).
      3. 
      
    3. Legge e copia: cin legge tre valori, poi i set li copiano dentro l'oggetto.
      4. 
      
    4. Stampa i dati e l'esito di entrambi.
      5. 
    
    
  
    
  
    cin >> e >> matr >> m;   // legge tre valori: 18 1001 7.5
Paolo.set_eta(e);          // l'età di Paolo diventa 18
Paolo.set_nmat(matr);      // la matricola di Paolo diventa 1001
Paolo.set_media(m);        // la media di Paolo diventa 7.5
    
  
    
    
    cout <<
    Le frecce vanno verso cout: i dati escono sullo schermo.
    
    
    ↔
    
    
    cin >>
    Le frecce vanno verso la variabile: i dati entrano dalla tastiera.
    
  
    
  
    Per Antonio si riusano le stesse variabili e, matr, m. Va bene: i valori di Paolo sono già stati copiati dentro l'oggetto Paolo, quindi sovrascrivere le variabili non li cancella.
    
  
    Ultima riga: return 0; dice al sistema che il programma è finito senza errori.
    
  
    
    
    Dopo aver letto i dati di Antonio, Paolo ha ancora i suoi?
    
    
    
    
    Esatto.Cambiano solo le variabili d'appoggio. Gli attributi di Paolo e quelli di Antonio sono caselle separate.

    Il foglietto
    
  
    Tutto in una pagina
    
  
    
    
    Classe
    Il progetto. class studente { ... }; con il ; finale.
    
    
    Oggetto
    Una cosa vera fatta col progetto. studente Paolo;
    
    
    Attributi
    I dati dentro la classe: int eta, nmat; float media;
    
    
    private / public
    Dati private (solo dentro la classe), metodi public (usabili da main).
    
    
    Costruttore
    Stesso nome della classe, nessun tipo. Parte da solo quando l'oggetto nasce.
    
    
    Overloading
    Stesso nome, parametri diversi: studente() e studente(int, int, float).
    
    
    get
    Legge: float get_media() { return media; }
    
    
    set
    Scrive: void set_media(float m) { media = m; }
    
    
    Usare un metodo
    Oggetto, punto, metodo: Paolo.set_eta(18);
    
    
    cout e cin
    cout << stampa, cin >> legge. endl va a capo.
    
    
    if / else
    if (media >= 6) {...} else {...}. >= = maggiore o uguale.
    
    
    return
    Esce dal metodo e consegna un valore. void = non restituisce niente.
    
    
    bool
    Solo true o false. bool promosso() { return media >= 6; }
    
    
    Errori classici
    Manca ; dopo la classe · void davanti al costruttore · cin << al posto di cin >> · metodo chiamato senza oggetto.
